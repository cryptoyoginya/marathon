# Обратная связь по скиллу

Правки по ходу использования. Этот файл **свежее SKILL.md и при конфликте
побеждает**. Читать перед началом.

Формат: дата и правило, коротко.

## 2026-08-30 (после сборки)
- Беговые тренировки трёх видов: интервалы, темповая, длинная. Без отдельного
  «лёгкого бега» в наборе недели при трёх беговых днях.

## 2026-08-30 (прогон на макете)
- Интейк строго по одному вопросу, блоком вопросов не выдавать.
- Вопрос про активности общий, без «твоего пилатеса»: скилл для многих.
- Спрашивать длительность собственных тренировок, чтобы время нагрузок в неделю
  считалось честно.
- Опция плавающих дней: набор нагрузок на неделю, не сетка по дням.
- В текстах плана нет средних точек, длинных тире, противопоставлений,
  описательных подписей и слова «игровые». У бега только целевой темп.
- Рекомендация недели из источников, разная на каждую неделю.
- Питание по этапам, не по неделям, бенто-сеткой.
- Карточки тренировок переворачиваются, на обороте короткое описание.
